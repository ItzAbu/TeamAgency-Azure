# Guida Utente

Benvenuto nell'applicazione **NomeProgetto**! Questa guida ti aiuterà a utilizzare tutte le funzionalità principali.

---

## Come giocare

- Accedi all'app e seleziona la modalità di gioco.
- Segui le istruzioni in-game per completare i livelli.

---

## Livelli Bot

Il progetto include diversi livelli di bot:

- **Facile**: risposte casuali, ideale per principianti.
- **Medio**: risposte basate su regole di base.
- **Difficile**: bot con intelligenza artificiale avanzata.

---

## Gestione Storico

L'app mantiene uno storico delle partite/attività:

- Visualizza lo storico dalla sezione "Storico" nel menu principale.
- Lo storico è ordinato per data e può essere filtrato.

---

## Export/Import

È possibile esportare o importare i dati storici:

- **Export**: clicca su "Esporta storico" e salva il file JSON.
- **Import**: clicca su "Importa storico" e seleziona un file JSON valido.
