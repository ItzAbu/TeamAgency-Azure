# Guida per Contributori

Benvenuto! Grazie per voler contribuire a **NomeProgetto**.

---

## Branching

- Utilizza `main` per la versione stabile.
- Crea branch per feature o fix chiamati `feature/nome` o `fix/nome`.
- Effettua merge tramite Pull Request con revisione.
